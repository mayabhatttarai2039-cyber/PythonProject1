# Automotive Fleet Tracker (OOP)
A lightweight Python application demonstrating **Object-Oriented- Programming (OOP)** and **Inheritance** structures modeled for automotive industry 🚘.
## 🎦 Project Goal
Simulate a dynamic commercial fleet management system that handles both electric vehicles (EV) and Internal Combustion Engine(ICU) Vehicles while maximizing code reusability.
## ⚒️ Concepts Practiced
**parent Blueprinting: ** Formulating shared attributes(brand, model, speed)
**Inheritance: ** Extending functionality to child tracks (`Electric Vehicle` and `Gas Vehicle`) via `super()`
** Behavior reusability: ** Inheriting Operational methods (`accelerate()`) while isolating custom child processes.
## 🚀 How it works 
The program instantiates separate vehicles in memory, accelerates their speeds independently, and runs fuel-specific actions like charging batteries or refueling tanks.
